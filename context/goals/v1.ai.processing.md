## Task brief · layers

```
Problem       Cerebro's stack has five layers — system tools, quarry, go-ai, docinfer
              (the inference library, settled at the brief), Cerebro —
              whose signatures separate design tasks would settle piecemeal; settle
              them once so every promotion builds to one shape.
Behaviors     1. A layers note in quarry's context states each boundary as
                 signatures or schemas: the tool contract (records, Markdown text
                 layer, metadata, media); quarry's API (inspection and routing,
                 index interfaces, event shapes); docinfer's API (inference
                 over go-ai, batches as made, cache, per-job cancellation);
                 go-ai's surface as docinfer and Cerebro use it; Cerebro's Queries, Commands, result
                 batches, manifest, and events. Each traces to a capstone task or
                 spike evidence.
              2. It settles contract versioning: schema "1" grown by addition, or "2".
              3. It measures each tool's duplicated text over the ~/docs corpus. Every
                 piece of text a file holds exists once: content in the Markdown text
                 layer, labels as kept plain-text fields; a structured field is cut only
                 when its text is already carried (in the Markdown or a kept field), or
                 it can't be plain text and has no processor. (amended at the brief)
              4. It lists what changes per tool and per quarry package from the spikes.
              5. A summary for data-intelligence.md is queued as a pending edit.
Test seams    the note's signatures against the spikes' code; the corpus measurement
Slices        1 tool contracts + payload measurement  2 quarry's API
              3 go-ai surface + Cerebro's API and events  4 change lists + pending edit
              5 the text-layer rule: missing text into the Markdown, mail body.text measured
              6 docinfer: the inference layer extracted from quarry (amended at the brief)
Out of scope  code; capstone build; gateway routing (kept transparent to go-ai)
Door          two-way — prose only, no release
```
