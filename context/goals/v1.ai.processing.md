**5 · Faults and inputs.**

Unit tests cover the cap and one element past it. An mbox test puts the deep message between two good ones, and both of their lines arrive.

**6 · Markdown and addresses.**
- Markdown order: stored HTML, HTML from the RTF, the text body, then the RTF's text. The RTF text comes from a second sink on the existing lexer and group stack: control words and ignorable groups are stripped, `\par` and `\line` become breaks, symbol words become their characters, and `\'hh` is decoded in `\ansicpg`. Unit tests cover a plain-RTF-only message and a `\fromtext` message.
- Inline images:
  - Attachments are read first, nested messages included.
  - Sources are rewritten to media names before htmd.
  - A `data:` image is written as media and listed in `media`.
  - An unmatched source is kept, with a warning.
  - `inline` is set when the Markdown links the attachment.
  - Unit tests over built messages cover each case.
- `smtp_address`: 0x39FE for a recipient and 0x5D01 for the sender, left out when absent, with a built-.msg unit test for the sender.
- Done when the goldens are re-recorded through `golden` and the check passes.

**7 · The content rule.**
- In the shared crate:
  - ICU4X 2.4.0 crates, required with `=`, give NFC, the dictionary-free UAX #29 word segmenter, the sentence segmenter, and general categories. A unit test asserts 18.0.0.
  - The URL tokens are angle-bracket URIs and GFM extended autolinks, compared after RFC 3986 §6.2.2 normalization.
  - Word tokens hold an L* or N* character and are compared case-sensitively.
  - The alignment trims the common prefix and suffix, then runs Myers' linear-space O((n+m)·D) algorithm. Past 10,000 edits it falls back to sentence membership.
  - Sentences end at UAX #29 boundaries and at line breaks.
- The Markdown-to-plain reader is pulldown-cmark 0.13.6, behind a Cargo feature that only mail enables.
- mail appends the missing sentences as one escaped paragraph when its Markdown came from HTML.
- Unicode-3.0 joins the accepted list.
- Rerun layers.md's "mail's text body against the Markdown" figures over ~/docs with this rule, and restate the tools and versions. Commit no script.
- Done when the five named goldens show their appended sentences, `msg/tika-test-outlook2003` and `pst/libyal-outlook` append nothing, and the root check passes.
